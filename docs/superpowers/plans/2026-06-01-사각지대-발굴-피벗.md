# 사각지대 발굴 피벗 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** KoreanSim을 "정책 사전 여론조사"에서 "정책 실행 시 사각지대·부작용 발굴 탐색 도구"로 피벗하고, 데이터 전용 대시보드 + 저장/불러오기 라운드트립을 구현한다.

**Architecture:** 갤럽 Prior·실험 변형 프리셋을 양단(FE+BE)에서 제거 → 응답에 `expected_complaint`+인구통계 배선 → 기존 인라인 합성 패스를 *병행 확장*(verbatim 라벨/denominator/inferred_based/예상민원 묶음) → `ResultPage`를 데이터 전용 대시보드로 재구성 → 스냅샷 라운드트립 보장.

**Tech Stack:** Backend FastAPI + pytest (`backend/`), Frontend React/Vite + vitest + Playwright (`frontend/`). LLM: OpenAI(`gpt-5-mini`).

**Spec:** `docs/superpowers/specs/2026-06-01-사각지대-발굴-피벗-design.md`

**공통 규칙:** 각 태스크는 테스트 먼저(TDD), 실패 확인 → 최소 구현 → 통과 확인 → 커밋. 백엔드 테스트 `cd backend && python -m pytest -q`, 프론트 `npm --prefix frontend test`.

> ⚠ **주의(스펙 §8):** `llm_client.py`의 `SYSTEM_PROMPT_OPENAI`/`build_agent_prompt`는 **두 번 정의**됨(라인 21/91, 218/266). **유효한 것은 두 번째 정의**다. 프롬프트 수정은 항상 두 번째 블록(≈91/266행)을 대상으로 하고, 죽은 첫 정의는 Phase 1에서 삭제한다.

- `frontend/src/result/ResultPage.tsx` — 데이터 전용 대시보드 재구성.
